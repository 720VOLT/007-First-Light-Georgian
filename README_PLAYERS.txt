007 FIRST LIGHT - GEORGIAN LOCALIZATION (OFFLINE INSTALLER BETA)
==============================================================

For PC Windows 10/11, x64. No internet or Python installation needed.

INSTALL
1. Close the game. Make sure game RPKG archives are ORIGINAL, without
   another localization/mod already installed. Back up files before testing.
2. Extract ALL contents of this ZIP into the main game folder containing
   Runtime\chunk0.rpkg and Runtime\chunk1.rpkg.
3. Double-click INSTALL_GEORGIAN.bat (or GeorgianInstaller.exe).
4. Confirm the detected game folder and type INSTALL when prompted.
5. Wait for "SUCCESS". Do not close the window mid-patch.
6. Launch game. Keep text language set to English, enable subtitles.

RESTORE
Close the game and double-click UNINSTALL_GEORGIAN.bat. Confirm RESTORE.
Keep Runtime\_georgian_localization_backup until successful restoration.

Important:
- This modifies YOUR locally installed chunk0.rpkg + chunk1.rpkg, not the
  game executable. Does NOT distribute original game archives.
- Uses small archive index + original-size recovery snapshots, not 50GB copies.
- Don't run over earlier modded game archives or after a game update.
- If install/uninstall fails, KEEP backups and report the full error text.
- This is an unofficial community beta. Compatibility with all game builds
  is not guaranteed. Use only with a legitimately obtained game copy.
- Never disable Windows security warnings solely to install the mod.
- The EXE is unsigned; SmartScreen may warn until software reputation grows.
- See SOURCE_AND_BUILD.md for project source and publisher build instructions.

Includes translation, Georgian font, and offline Python/toolkit runtime.
All installer code is included for review. Uninstall requires the same folder.
